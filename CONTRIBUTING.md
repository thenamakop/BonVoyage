# Contributing

The working agreement for a one-developer project.

- Work in one-week sprints from Monday to Sunday, with a review on Sunday.
- Name branches `feat/<issue>-<slug>`, `fix/<issue>-<slug>`, `chore/<slug>` or `docs/<slug>`, and write Conventional Commits (`feat:`, `fix:`, `test:`, `docs:`, `chore:`, `refactor:`), as in AGENTS.md section 12.
- Every change goes through a pull request. CI must be green. Merge with squash.
- Keep pull requests under about 400 changed lines. The scaffold and generated migrations are exempt.
- UI changes include screenshots at 360 px and desktop widths.
- A change is done when it meets the Definition of Done in AGENTS.md section 13.
